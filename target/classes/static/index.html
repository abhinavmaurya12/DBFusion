      Help and shortcuts
      
  
      
    
      SQL Commands
      
    
      Ctrl+Enter run the statement at the cursor (or the selection). F5 run the whole script. Ctrl+Shift+F format. Statements end with ;. In Oracle, end PL/SQL blocks with a line holding only /.
      
    
      SQL*Plus commands work in Oracle: DESC table, SHOW USER, SHOW ERRORS, EXEC proc(1), SET SERVEROUTPUT ON, PROMPT text.
      
    
      Other pages
      
    
      Object Browser: click a table, double-click a cell to edit it. Click the → on a row to open it in the row inspector. User Manager (Oracle): create, lock, unlock, expire, reset and drop users while connected as SYSTEM. Ctrl+K opens the command palette.
